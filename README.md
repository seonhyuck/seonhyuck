### 백엔드 개발자

금융 고객사에 공급되는 솔루션의 백엔드를 개발하며, 인증·보안과 데이터를 주로 다룹니다.
새로운 기술은 그 결과를 검증할 수 있는 구조와 함께 도입해야 한다고 생각합니다.

**하고 있는 일**

- Java · Spring Boot 기반 백엔드 개발 (약 1년 6개월)
- REST API · DB 스키마 설계 및 구현
- 인증 · 접근 통제 · 감사로그 등 정보보안 개발
- AI Agent 실무 적용 — STT 교정 후보 제시, 운영 환경 배포

**기술**

`Java` `Spring Boot` `JPA` `QueryDSL` `MyBatis`
`Oracle` `MySQL` `MariaDB`
`GitLab` `Jenkins` `Swagger`
